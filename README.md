## 🚀 Projeto em Destaque (SOC Lab)

### 🛡️ [Analisador de Logs Web Automatizado em Python](https://github.com/ninimelo/analisador-logs-soc)

Projeto educacional desenvolvido em **Python** para simular regras de correlação de um motor **SIEM**, auxiliando na triagem automatizada de eventos suspeitos em logs web.

- **Análise de logs:** processamento de registros de servidores Apache e Nginx utilizando Expressões Regulares (**Regex**).
- **Detecção de atividades suspeitas:** identificação de possíveis ataques de força bruta por meio de erros HTTP 401 e tentativas de acesso a arquivos e diretórios sensíveis, como `.env` e `/admin`, associadas a erros HTTP 404.
- **Triagem de incidentes:** análise pelo terminal, classificação por severidade e geração automática de relatórios em `.txt`.

## 🗂️ Outros Projetos

### 🔍 [Verificador de Hash integrado ao VirusTotal](https://github.com/ninimelo/verificador-hash-virustotal)

Ferramenta educacional desenvolvida em **Python** para auxiliar na triagem inicial de arquivos suspeitos por meio do cálculo de hash SHA-256 e consulta à API v3 do VirusTotal.

- Cálculo de hash SHA-256 de arquivos locais.
- Consulta de estatísticas de detecção por meio da API REST.
- Tratamento de erros comuns de conexão e consulta.
- Uso de variáveis de ambiente para proteger a chave da API.

### 📧 [Análise de Phishing — PayPal](https://github.com/ninimelo/analise-phishing-paypal)

Projeto educacional que simula a triagem de um e-mail suspeito sob a perspectiva de um Analista SOC (Blue Team).

- Identificação de possíveis indicadores de comprometimento (**IoCs**).
- Análise de domínio suspeito e identificação de typosquatting.
- Investigação de links encurtados e possíveis tentativas de roubo de credenciais.
- Classificação do e-mail como phishing e elaboração de recomendações de mitigação.
