### 🚀 Projeto em Destaque (SOC Lab)
#### 🛡️ [Analisador de Logs Web Automatizado em Python](https://github.com/ninimelo/analisador-logs-soc)
Desenvolvi um script em **Python** focado em simular as regras de correlação de um motor de **SIEM** para triagem automatizada de incidentes.
- **Parsing Estruturado:** Análise de logs de servidores (Apache/Nginx) utilizando Expressões Regulares (**Regex**).
- **Detecção de Ameaças:** Regras automáticas para identificar **Ataques de Força Bruta** (Erros 401) e **Varredura Ativa de Diretórios/Bots** (Erros 404 em arquivos críticos como `.env` e `/admin`).
- **Resposta a Incidentes:** Interface de varredura em tempo real via terminal e exportação automática de relatórios de incidentes estruturados (`.txt`) com cálculo de severidade.
